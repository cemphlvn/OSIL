# spec/ invariants (evaluated on every spec diff)
1. Univocity: one term = one meaning, spec-wide (see univocity-lint).
2. Every nonroot term defined, Aristotelian form, essential features, no circularity.
3. Triple representation: new/renamed constructs ship grammar production + corpus
   example in the same change.
4. Sovereignty: no text may redefine an external ecosystem's normative semantics.
5. MUST/SHOULD level text requires human ratification.
