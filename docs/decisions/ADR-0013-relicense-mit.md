# ADR-0013: Relicense Apache-2.0 -> MIT

Date: 2026-08-18 · Status: RATIFIED (maintainer instruction: "lets make it
MIT for now").

Context: hours after open-sourcing under Apache-2.0 + DCO, the maintainer
chose MIT. Relicensing is clean: sole copyright holder (all 48 commits share
one identity), zero external contributions in the interval.

Decision: MIT repo-wide; DCO retained (license-independent); copyright line
names the maintainer.

Consequences: OSI-approved, so the LF AI & Data path is unaffected. Recorded
trade-off: MIT has no explicit patent grant (Apache-2.0 did); the "for now"
is preserved as intent — revisiting before foundation submission stays open,
and any future relicense needs ratification plus, once external contributors
exist, their consent.
