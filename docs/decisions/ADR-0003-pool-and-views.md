# ADR-0003: One canonical pool, many views (corpus/curriculum; instruction projections)
Date: 2026-08-12 · Status: accepted
Context: a conformance example ordered by grammar coverage IS a lesson ordered by
pedagogy; CLAUDE.md/AGENTS.md/SKILL.md carry overlapping agent instructions.
Duplicated content drifts, always.
Decision: content lives once (conformance/corpus; improvable/INDEX + GOVERNANCE);
orderings and audiences are VIEWS (curriculum paths reference ids; CLAUDE.md and
AGENTS.md are projections of the canonical sources). View-drift is a CI failure.
Consequence: reachability/resolution loops replace content review for views.
